Officoman Launcher portable mode

While this file sits next to officoman-launcher.exe, Officoman Launcher keeps its settings, its
download cache and its record of installed apps in the OfficomanLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Officoman Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Officoman Launcher) instead.
If OfficomanLauncherData can't be written (for example on a read-only drive), Officoman Launcher says
so and uses %APPDATA%\Officoman Launcher instead.
