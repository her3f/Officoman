Sheaf portable mode

While this file sits next to sheaf.exe, Sheaf keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the SheafData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Sheaf with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Sheaf and
%LOCALAPPDATA%\Sheaf) instead. If SheafData can't be written (for example on a read-only
drive), Sheaf says so and uses the per-user folders instead.
