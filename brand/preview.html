What is and isn’t final

Real: the geometry, the palette, the naming.
  • The wordmark type is live text in Segoe UI — fine for a README, but before you print it anywhere, convert it to outlines in a proper typeface.
  • App icons above are CSS placeholders, not finished artwork.
  • Neither name nor mark has been registered. A search found no existing use of either, which is not the same as a trademark clearance.
