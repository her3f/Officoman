What they have in common

Written in Rust

One language from the document model to the pixel, so the same code runs natively and in the browser.

Works offline

No account, no telemetry, no server round trip. Your documents stay on your disk.

Real file formats

.docx, .xlsx, .pptx and PDF — files you can hand to anyone, not a private format.

Scriptable

Every action is a command, so the CLI and AI agents can drive the same buttons you click.

Four platforms

macOS, Windows, Linux and BSD, plus a WebAssembly build.

MIT or Apache-2.0

Dual-licensed, forkable, and yours to build on.
