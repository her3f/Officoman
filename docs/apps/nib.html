Documents

Nib

A full word processor with styles, references, review tools and mail merge — written from scratch in Rust, native on macOS, Windows, Linux and BSD, and in the browser.

.docx read and write · .doc import · PDF export · .odt, .rtf, .html, .md, .tex, .txt

What it does

Writing

IME input, smart quotes, AutoCorrect, list autoformat, regex find and replace.

Formatting

Fonts, styles, character and paragraph spacing, tabs with leaders, borders.

Tables

Merge and split, banded styles, repeating header rows, sort, formulas, text to table.

References

Table of contents, footnotes, citations in APA/MLA/Chicago/IEEE, index.

Review

Track changes, margin comments, compare documents, accessibility checker.

Mailings

Mail merge from CSV, envelopes and labels.

Status

Nib is derived from WordCraft. The source is imported in this repository under apps/nib and has been rebranded but not yet rebuilt or tested here, because no Rust toolchain build has been verified on this tree. Treat it as early: build it, run the tests, and expect rough edges.
