PDF

Sheaf

A PDF workbench: read, search, reorganize, combine, split and protect documents without handing them to a server.

PDF read and write — no account, no telemetry

What it does

Read

Fast rendering, text selection, search, bookmarks and threaded comments.

Find

Search across a document, select and copy text exactly as it is drawn.

Organize

Reorder, rotate, delete and insert pages like cards on a table.

Combine

Merge and split documents without losing a page or a link.

Protect

Open protected documents and respect their permissions.

Everywhere

Native on macOS, Windows, Linux and FreeBSD, and in the browser.

Status

Sheaf is derived from PdfCraft. The source is imported in this repository under apps/sheaf and has been rebranded but not yet rebuilt or tested here, because no Rust toolchain build has been verified on this tree. Treat it as early: build it, run the tests, and expect rough edges.
