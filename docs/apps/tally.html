Spreadsheets

Tally

A spreadsheet built for real data work: styled tables, totals rows, conditional formatting, sparklines and live charts, in pure Rust.

.xlsx read and write · .xls import

What it does

Tables

Styled tables with banded rows, totals rows, filter buttons and data bars.

Formatting

Conditional formatting, arrow icon sets, sparklines inside cells.

Charts

Column and pie charts that follow the data as it changes.

Formulas

A formula engine written in Rust, with the worksheet as a first-class object.

Files

Opens and saves .xlsx and imports .xls.

Automation

Every action is a command, scriptable from the CLI and driveable over MCP.

Status

Tally is derived from GridCraft. The source is imported in this repository under apps/tally and has been rebranded but not yet rebuilt or tested here, because no Rust toolchain build has been verified on this tree. Treat it as early: build it, run the tests, and expect rough edges.
