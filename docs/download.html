Portable builds: unzip anywhere and run the `.exe`. Nothing is installed and no registry keys are written. They are unsigned, so Windows SmartScreen may warn on first run.

Other platforms

macOS, Linux and FreeBSD builds are produced by each app's own packaging scripts under apps/<app>/packaging/. They need a macOS or Linux host; they cannot be cross-built from Windows.
