A few things before you start.

01

Pick your package

On Windows, use the MSI installer for shortcuts and file associations, or extract the portable ZIP. macOS and Linux downloads are archives.

02

Keep your files close

Work with local documents. These are early builds, so keep backups of important files while trying them out.

03

Check before opening

Packages are unsigned. Your operating system may show a security prompt. Verify the download source and file checksum before running it.
