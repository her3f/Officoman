.msi installs normally: Start Menu shortcut, Add/Remove Programs, and `.docx`/`.xlsx`/`.pptx`/`.pdf` in “Open with”. It asks whether to install for you only or for everyone. .zip is portable: unzip and run, nothing written to the system. Neither is code-signed, so SmartScreen warns on first run.

Other platforms

macOS, Linux and FreeBSD builds are produced by each app's own packaging scripts under apps/<app>/packaging/. They need a macOS or Linux host; they cannot be cross-built from Windows.
