.msi installs normally: Start Menu shortcut, Add/Remove Programs, and `.docx`/`.xlsx`/`.pptx`/`.pdf` in “Open with”. It asks whether to install for you only or for everyone. .zip is portable: unzip and run, nothing written to the system. Neither is code-signed, so SmartScreen warns on first run.

Other platforms

Only Windows builds exist today. The applications are written to run on macOS and Linux as well, but those binaries must be produced on those systems — neither can be cross-built from Windows — and that build has not run yet.

The build recipe for both is committed: a CI workflow builds all four apps on Ubuntu and macOS and attaches the archives. It is waiting to be enabled. Until it runs, the table above is the whole catalogue.
